Терминал Windows CMD

  • dir - расшифровывается как "Directory", выводит список файлов и папок в текущей директории.
  • cd - расшифровывается как "Change directory", используется для смены текущей папки.
  • mkdir - расшифровывается как "Make directory", используется для создания новой папки.
  • date - показывает или изменяет текущую дату.
  • time - показывает или изменяет текущее время.
