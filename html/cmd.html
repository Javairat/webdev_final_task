Командная строка Windows

📋 Управление файлами и папками

  • cd — смена текущей директории
  • dir — просмотр содержимого папки
  • mkdir — создание новой папки
  • rmdir — удаление папки
  • copy — копирование файлов
  • move — перемещение файлов
  • del — удаление файлов
  • cls — очистка экрана
  • echo — вывод текста на экран
  • exit — закрытие командной строки
  • ping — проверка соединения с сервером
  • ipconfig — просмотр сетевых настроек
  • systeminfo — информация о системе
  • tasklist — список запущенных процессов
  • taskkill — завершение процесса по PID
